## MPI_Send и MPI_Recv

```cpp
MPI_Send(&count, 1, MPI_INT, p, 100, MPI_COMM_WORLD);
MPI_Recv(&recv_counts[rank], 1, MPI_INT, 0, 100, MPI_COMM_WORLD, MPI_STATUS_IGNORE);
```

### Объяснение параметров:

**`MPI_Send(buffer, count, datatype, dest, tag, comm)`**

* **`buffer`** — адрес данных, которые мы отправляем (`&count` — количество элементов в буфере для процесса `p`)
* **`count`** — сколько элементов отправляем (1 элемент типа `MPI_INT`)
* **`datatype`** — тип данных (`MPI_INT` — целое число)
* **`dest`** — номер процесса-получателя (0-based, тут `p`)
* **`tag`** — метка сообщения, чтобы различать сообщения (`100`)
* **`comm`** — коммуникатор MPI (`MPI_COMM_WORLD` — все процессы)

**`MPI_Recv(buffer, count, datatype, source, tag, comm, status)`**

* **`buffer`** — куда складываем полученные данные (`&recv_counts[rank]`)
* **`count`** — сколько элементов принимаем (1 элемент типа `MPI_INT`)
* **`datatype`** — тип данных (`MPI_INT`)
* **`source`** — от какого процесса получаем (`0`)
* **`tag`** — метка сообщения, совпадающая с `MPI_Send` (`100`)
* **`comm`** — коммуникатор MPI
* **`status`** — информация о сообщении, можно `MPI_STATUS_IGNORE`, если не нужен

**Что происходит в примере:**

* Процесс 0 отправляет каждому другому процессу количество элементов, которые ему надо получить.
* Остальные процессы читают это число, чтобы заранее знать размер своего буфера для данных.

## Как работает параллельная сортировка (Bucket Sort + MPI + OpenMP)

Допустим, что есть **16 элементов** и **2 процесса**, каждый с 2 потоками (OpenMP):

```
Элементы: [0.12, 0.34, 0.05, 0.78, 0.23, 0.56, 0.90, 0.67, 0.11, 0.44, 0.32, 0.88, 0.01, 0.99, 0.66, 0.42]
Процессы: 0 и 1
Бакеты на процесс: 2
```

### Шаги:

**Разделение на бакеты (корзины)**

* Процесс 0 создаёт `total_buckets = nprocs * buckets_per_proc = 2*2 = 4`
* Каждое число попадает в бакет по формуле:

  ```cpp
  bucket_idx = floor(x / bucket_width)
  ```
* Получаем 4 корзины:

```
Bucket 0 (0.0–0.25): [0.12, 0.05, 0.23, 0.11, 0.01]
Bucket 1 (0.25–0.50): [0.34, 0.44, 0.32, 0.42]
Bucket 2 (0.50–0.75): [0.56, 0.67, 0.66]
Bucket 3 (0.75–1.0) : [0.78, 0.90, 0.88, 0.99]
```

**Назначение бакетов процессам**

* Каждый процесс получает определённые бакеты:

```
Process 0: Bucket 0 и 1
Process 1: Bucket 2 и 3
```

* Процесс 0 отправляет каждому процессу данные для его бакетов (`MPI_Send` / `MPI_Recv`).

**Локальная сортировка**

* Каждый процесс сортирует свои элементы **локально**.
* Если процессу выделено несколько потоков (OpenMP), он делит локальный массив на сегменты, каждый сегмент сортируется параллельно:

```
Process 0 local: [0.12, 0.05, 0.23, 0.11, 0.01, 0.34, 0.44, 0.32, 0.42]
  Поток 0: [0.12,0.05,0.23,0.11]
  Поток 1: [0.01,0.34,0.44,0.32,0.42]
  После параллельной сортировки и слияния: [0.01,0.05,0.11,0.12,0.23,0.32,0.34,0.42,0.44]

Process 1 local: [0.56,0.67,0.66,0.78,0.90,0.88,0.99]
  Поток 0: [0.56,0.67,0.66]
  Поток 1: [0.78,0.90,0.88,0.99]
  После сортировки и слияния: [0.56,0.66,0.67,0.78,0.88,0.90,0.99]
```

**Сбор результатов на root (процесс 0)**

* После сортировки каждый процесс отправляет свои данные процессу 0 (`MPI_Gatherv`)
* Процесс 0 объединяет все отсортированные блоки в один массив:

```
Final sorted: [0.01,0.05,0.11,0.12,0.23,0.32,0.34,0.42,0.44,0.56,0.66,0.67,0.78,0.88,0.90,0.99]
```

Все элементы отсортированы, и сортировка прошла параллельно на **нескольких процессах и потоках**.

## Как работает алгоритм Bucket Sort на примере

Представим массив из **10 элементов** и **4 корзины**:

```
Элементы: [0.12, 0.45, 0.23, 0.78, 0.34, 0.56, 0.89, 0.01, 0.67, 0.11]
Корзины: 0 [0–0.25), 1 [0.25–0.5), 2 [0.5–0.75), 3 [0.75–1)
```

### Шаги:
**Генерация данных**

* Случайные числа от 0 до 1.
* В нашем примере числа уже есть.

**Распределение по корзинам**

```
Корзина 0: [0.12, 0.23, 0.01, 0.11]
Корзина 1: [0.45, 0.34]
Корзина 2: [0.56, 0.67]
Корзина 3: [0.78, 0.89]
```

**Сортировка каждой корзины**

```
Корзина 0: [0.01, 0.11, 0.12, 0.23]
Корзина 1: [0.34, 0.45]
Корзина 2: [0.56, 0.67]
Корзина 3: [0.78, 0.89]
```

**Слияние всех корзин**

* Объединяем корзины в один массив:

```
[0.01, 0.11, 0.12, 0.23, 0.34, 0.45, 0.56, 0.67, 0.78, 0.89]
```

**Проверка корректности**

* Проверяем, что каждый следующий элемент ≥ предыдущего.

Результат — отсортированный массив.
